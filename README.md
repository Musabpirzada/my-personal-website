# Syed Musab Pirzada - Personal Website

A responsive, single-page personal portfolio created from the supplied CV.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder.

## Publish

This is a dependency-free static site. Upload the contents of this folder to any static host, such as GitHub Pages, Netlify, Cloudflare Pages, or Vercel.

## Files

- `index.html` - page content and semantic structure
- `style.css` - responsive visual design
- `script.js` - lightweight scroll-reveal interaction
